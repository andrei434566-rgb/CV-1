# Локальное дообучение Qwen на открытых материалах

Этот путь обучает отдельный адаптер Qwen3-VL-2B: коротким исходным классам пород, русским теоретическим ответам и обычному общению. Он сохраняет базовую модель и действующие адаптеры приложения.

Первый запуск завершён 23.10.2026: [результаты и решение по кандидату](QWEN_SOURCE_PILOT_2026-10-23.md). Классификация улучшилась, но кандидат не принят для общего чата из-за ошибок в теории и регрессии общения.

Следующий этап: [раздельное обучение фото и теории с новыми источниками](README_QWEN_ROUND2_RU.md).

## Данные первого запуска

- Mendeley: 60 учебных фрагментов на каждый из четырёх классов, всего 240.
- Чистый DCID-512-7: 60 на каждый из семи классов, всего 420. Другие версии DCID и шумовые данные не смешиваются с ним.
- Теория: 183 ранее подготовленных ответа с указанием источников.
- Общение: 12 коротких примеров приветствий, уточнений и помощи в приложении.
- Всего: **855 учебных примеров**. Отдельно сохранены 88 проверочных фото, 24 вопроса по теории и 4 разговорных запроса. Для одинакового сравнения до/после используются все 88 фото, 8 одинаковых вопросов из 24 и все 4 разговорных запроса.

Метки пород переведены буквально. Из них не создаются подробные описания, глубины, фации или условия осадконакопления. Shale и mudstone сохраняют разные исходные обозначения. Неподтверждённые пары UKCS/IODP и нарезки Р-41 не включены.

Mendeley заново разделён по скважинам; DCID не содержит подтверждённых идентификаторов скважин. Одинаковые пиксели между частями проверяются по исходным хешам и по выбранным фактическим изображениям. Не используется test **нового подготовленного разбиения**. Исходные папки Mendeley train/val/test перегруппированы: они не были раздельными по скважинам, и некоторые исходные test-файлы вошли в новый train. Валидационные скважины Mendeley уже оценивались в старых экспериментах, поэтому нельзя объявлять их совершенно новым внешним тестом.

`training_approved` в этом пилоте означает разрешение использовать исходный класс или подготовленную текстовую пару для обучения. `geology_approved` остаётся `false`: геологическая проверка специалистом не подменяется запуском скрипта. DCID имеет условия CC BY-NC 4.0; они записываются в происхождении кандидата.

## Повторить на другом компьютере

Нужны подготовленные Mendeley и DCID в библиотеке приложения, локальная Qwen3-VL-2B-Instruct и Python с CUDA PyTorch, Transformers и PEFT. Библиотека выбирается через `--storage`; папки модели и Python можно указать свои. Обучение и сравнение не обращаются в интернет.

Сначала проверьте план без записи:

```powershell
python scripts/prepare_qwen_source_pilot.py --dry-run
```

Подготовьте новую папку с манифестами:

```powershell
python scripts/prepare_qwen_source_pilot.py --write --output-dir open_datasets/qwen_source_pilot_v1
```

По умолчанию теория берётся из соседней `vlm_core_v1/data/knowledge`. При другом размещении задайте `--theory-train` и `--theory-holdout`; версии исходных файлов также лежат в `vlm_source/theory_v5`. Скрипт сохраняет готовый `mixed.jsonl` и системный текст приложения `system_prompt.txt`.

Пример запуска из корня проекта:

```powershell
$taskPython = '..\vlm_core_v1\.venv\Scripts\python.exe'
$taskBase = '..\vlm_core_v1\model_cache\hub\models--Qwen--Qwen3-VL-2B-Instruct\snapshots\89644892e4d85e24eaac8bacfd4f463576704203'
& $taskPython -u scripts/train_qwen_source_pilot.py `
  --manifest open_datasets/qwen_source_pilot_v1/mixed.jsonl `
  --eval-manifest open_datasets/qwen_source_pilot_v1/val_visual.jsonl `
  --val-text-manifest open_datasets/qwen_source_pilot_v1/holdout_theory.jsonl `
  --val-conversation-manifest open_datasets/qwen_source_pilot_v1/holdout_conversation.jsonl `
  --system-prompt-file open_datasets/qwen_source_pilot_v1/system_prompt.txt `
  --model $taskBase `
  --output-dir ../vlm_core_v1/outputs/qwen_source_candidate_v1
```

Существующие папки не перезаписываются. Параметры первого запуска: один проход, rank 8 для языковых q/v-проекций, шаг обучения `5e-5`, фото до 280 px, batch 1 и накопление градиента за четыре примера. Планировщик использует целое число `warmup_steps`, совместимое с установленной Transformers 5.18. Параметры проверяются до загрузки весов.

## Результат и проверка

В папке запуска сохраняются:

- `adapter/` — новый LoRA и процессор;
- `run_config.json` — модель, параметры, версии и хеши входных файлов;
- `baseline_responses.jsonl` и `candidate_responses.jsonl` — исходные ответы до и после;
- `baseline_metrics.json`, `candidate_metrics.json`, `metrics.json` — сравнение по каждому источнику;
- `progress.jsonl` — ход работы; при ошибке — `failure.json`.

Классификационные метрики требуют точного нормализованного названия из списка. Это строгая проверка исходного класса и формата ответа: семантически близкая другая формулировка может считаться неизвестным ответом. Это не оценка правильности полного геологического описания, обстановки осадконакопления или 92 фаций проекта.

Теоретические и разговорные ответы сохраняются для отдельной содержательной проверки. Снижение учебной ошибки не означает роста точности. Подключение кандидата к рабочему приложению выполняется после проверки регрессий и подходящих реальных фото с описаниями.

Теоретическая выборка содержит близкие перефразировки учебных тем. Она подходит для проверки поведения и регрессий; это не независимая оценка освоения новых геологических знаний. JSONL с изображениями содержат абсолютные пути на текущем ПК: после переноса библиотеки на другой компьютер подготовьте манифесты заново.

Если обучение прервалось до изменения весов, полный исходный контрольный прогон можно повторно использовать через `--reuse-baseline-dir`. Скрипт проверяет модель, версии, все хеши манифестов, системный текст, настройки генерации, идентификаторы, вопросы и эталоны каждой записи; метрики пересчитываются из сохранённых ответов. Старый прогон остаётся неизменным.
