# CV-1 Kern Analyzer 2.2.0 Vision

Рабочий режим без генеративных LLM/VLM: YOLO определяет геометрию, обученный
ConvNeXt-Tiny предлагает литологию, описание составляется по фиксированным
формулировкам. Помощник использует локальные справочники и поиск документов.

- [Как устроен текущий режим и как им пользоваться](CV1_VISION_RU.md).
- [Результаты сравнения EfficientNet-B0 и ConvNeXt-Tiny](research_reports/vision_20261104/RESULTS_RU.md).
- [Подробные метрики и происхождение данных](research_reports/vision_20261104/comparison.json).

Обе модели обучены на 40 000 размеченных фрагментах. На тесте из 400 фрагментов
четырёх отдельных скважин: EfficientNet-B0 — 90,5%, ConvNeXt-Tiny — 93,75%.
Архитектура и веса выбраны по macro-F1 валидации, до оценки теста.
Тест — существующая исследовательская база, а не новое слепое испытание.

**Поддерживаются три литологии и фон: песчаник, известняк, глинистая порода
(shale), фон/не керн. Фации ещё не обучены.** На сканах Р-31 классификатор
пока неуверен; автоматические ответы требуют проверки и не подтверждаются
для обучения сами. Гранулометрия, биотурбация и гидродинамический режим
не выводятся из названия породы. Все поля редактируются геологом.

## Запуск рабочей копии

На подготовленном компьютере используйте обычный ярлык Kern Analyzer или
`launch_latest.py` в текущем Python-окружении. `models/vision/current.json`
указывает на выбранную версию CNN. В меню помощника можно выбрать другую
папку классификатора и папки локального справочника.

Полный набор весов выбранной модели отдельно:
`transfer/out/cv1-vision-v2.2.0/CV1_Vision_Model.zip`.
Архив содержит карточку, контрольные суммы, атрибуцию и CNN, без исходных фото.

Для чистой установки нужны Python 3.11+, согласованные PyTorch/TorchVision
и зависимости из `requirements.txt`. Проверенное окружение этого обучения:
PyTorch 2.6.0+cu126, TorchVision 0.21.0+cu126. При запуске приложения модели
из интернета не скачиваются. Инференс и поиск работают локально.

## Сохранённые функции

Сборка колонки, маски и глубины, ручные исправления, основной справочник
специалиста, пары фото–Word/Excel и типовой Excel с красной подсветкой проблем.
Геометрия не меняется при применении результатов классификатора.

Теория пополняет поиск и готовые справочные ответы. Для обучения визуальных
классов нужны изображения с настоящими метками. Старые тестовые фации,
синтетические параметры и неподтверждённые ответы прежней VLM не входят
в текущую обучающую базу.

CV-1 читает проекты старых версий с сохранёнными полями `__vlm_*`.
Новые описания создаёт локальный процесс CV-1 Vision.
