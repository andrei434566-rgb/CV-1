# Kern Analyzer

Новый маршрут CV-1: **фото → ваш `best.pt` (геометрия) → локальная Qwen3-VL-2B с выбранным LoRA или без него → проверка → Excel**. [Настройка, ограничения и обучение](CV1_ARCHITECTURE_RU.md).

Окно **«⚙ справа сверху → Обучение… → Фото + Word»** принимает папку фотографий и один Word
с разделами `Фото 0001`, `Фото 0002` и т. д. Проверка покажет совпадения и
ошибки; полные описания можно просмотреть рядом с фото, подготовить проверенные
пары и запустить локальное дообучение. [Формат и порядок работы](README_WORD_PHOTO_TRAINING_RU.md).

Типовой отчёт можно выгрузить в любой момент: паспорт скважины, фации,
описания и границы столбиков не обязательны. Известные значения сохраняются,
незаполненные поля остаются пустыми. В пустом проекте выгружается чистый бланк Excel.
В Excel проблемные поля подсвечиваются красным: пропуски, неизвестная фация,
явно неуверенные ответы и некорректные интервалы/исходные данные расчётов.
Подсветка пересчитывается при исправлении ячеек.

Через **⚙ справа сверху → Основной источник…** можно подключить свои Word,
Excel, текстовые PDF, TXT/Markdown или CSV. Локальные копии материалов имеют
приоритет перед общими знаниями для **фаций и гидродинамического режима**.
Эта настройка не меняет веса VLM и не подменяет наблюдения по фото текстом
справочника. [Как подключить материалы на другом ПК](README_PRIMARY_SOURCE_RU.md).

### Теория и поправки специалиста

Перетащите текстовый PDF, DOCX, TXT, Markdown, CSV или JSON в чат. Приложение
прочитает документ в фоне, сохранит его локально и будет искать подходящие
выдержки для ответа; после перезапуска они останутся доступны. Если PDF
состоит из сканов без текстового слоя, приложение сообщит, что нужен OCR.
Добавление документа не изменяет веса модели: для отдельного дообучения LoRA
нужен подготовленный набор и запуск обучения с последующей проверкой.

Исправьте параметры интервала в карточке и нажмите «Сохранить»: проект с
поправкой сохранится автоматически, а для нового проекта создастся черновик.
Отметьте «Описание проверено — запомнить для ИИ», чтобы использовать текст как
проверенную информацию именно для этого интервала. Проверка описания не заменяет
отдельную проверку фации и границ для обучения. После изменения текста или
границы подтверждение нужно повторить.

При выборе фации карточка сохраняет её связь с исходным классом и конкретным
фото/контуром YOLO. Если модель выделяет только геометрию, её метка не считается
готовой фацией. Связь доступна помощнику в контексте выбранного интервала; она
не переносится автоматически на другие фотографии и не переобучает модель.
При подготовке пар для дообучения в учебный ответ добавляется только фация,
для которой отдельно подтверждены и описание, и фация с границами; исходный
класс YOLO сохраняется в метаданных. Это подготовка данных, а не запуск обучения.

Открытые наборы керна подключены через **Настройки → Учебные материалы из открытых источников…**. Загрузка, подготовка, проверка фото с описаниями и обучение описаны в [инструкции](README_OPEN_DATASETS_RU.md).

[Фактически подготовленные материалы и результаты проверок](OPEN_DATASETS_STATUS_2026-10-22.md).

[Локальное дообучение Qwen на подготовленных данных](README_QWEN_TRAINING_RU.md): подготовка сбалансированного набора, отдельный адаптер и одинаковая проверка до/после.

Для разработки в VS Code смотрите [инструкцию по работе с CV-1](DEVELOPMENT_RU.md).

Для переноса приложения, локальной VLM и моделей сегментации на другой ПК
смотрите [инструкцию CV-1](transfer/README_RU.md).

## Новое окно и локальный ИИ-ассистент

Главное окно теперь разделено на навигацию слева, прежнюю интерактивную рабочую область в центре и панель ИИ справа. Команды импорта, разметки, обучения и настройки остались в меню ⚙ «Инструменты». По скважинам и слоям можно перемещаться через дерево проекта и список в верхней панели.

Ассистент запускает **локальную Qwen3-VL-2B**. Подготовленный быстрый движок llama.cpp работает только на этом компьютере и использует внутреннее соединение через loopback; адрес внешнего сервера и интернет для ответов не нужны. Если быстрый движок не подготовлен, используется локальный Transformers/Python с `local_files_only`. Первый ответ включает загрузку весов, следующие используют уже загруженную модель. Свободный чат использует базовую Qwen, а описание выбранного фрагмента фото может использовать совместимый проверенный адаптер и заполняет три поля VLM в проекте и итоговом Excel: ассоциация, обстановка, краткое описание. Эти значения можно исправить в карточке фации; они остаются черновиком до проверки геологом и не превращаются в подтверждённую обучающую разметку.

В ⚙ → «Настроить локальную VLM и папки…» задаются локальные Python с CUDA, база Qwen3-VL-2B, папка LoRA и материалы для поиска. По умолчанию выбран режим **«Базовая модель»**; сохранённые старые адаптеры не активируются автоматически. Чтобы подключить проверенную LoRA, выберите **«Модель с дообучением»**. Соседняя папка `vlm_core_v1` помогает найти базу и среду; при другом размещении укажите пути вручную. Веса и CUDA Python не входят в основной EXE. Поиск поддерживает TXT, MD, CSV, TSV, JSON, JSONL, DOCX, XLSX и текстовые PDF. Файлы не отправляются наружу.

В чате Enter отправляет сообщение, Shift+Enter добавляет строку. Короткие обращения («работаешь?», «что умеешь?» и приветствия) получают мгновенный локальный ответ без загрузки весов. Общие и визуальные вопросы имеют отдельную историю. Справочные вопросы могут получить ответ из локальных карточек; ссылки показываются только по запросу. Первый содержательный запрос к Qwen включает загрузку весов; следующие интервалы используют тот же процесс.

Справочник v5 добавляет источники по биотурбации, буровым нарушениям, границам зернистости и ограничениям цвета фото. Ссылки показываются в чате по запросу. Экспериментальный текстовый адаптер v5 обучен, но после контрольных вопросов не включён: он повторяет существенные геологические ошибки базовой модели. [Данные и решение](vlm_source/theory_v5/README_RU.md) сохранены для дальнейшей доработки.

Для общих вопросов по геологии добавлены 14 локальных справок по проверенным открытым публикациям: различение пород, матрикса и цемента, слоистость, карбонатные классификации и биотурбация. Подходящие справки передаются Qwen автоматически; сведения о конкретной скважине и описание фото идут прежним маршрутом. [Материалы, отдельные опыты SFT/DPO и результаты сравнения](vlm_source/grounded_theory_v1/README.md) опубликованы вместе с ошибочными ответами для аудита. Эти результаты не устанавливают точность распознавания фаций; отклонённые адаптеры не включаются в приложение.

Расширенный опыт SFT использовал 344 текстовые строки и 110 новых карточек по 22 темам. В корректном сравнении быстрого движка адаптер дал 7 полностью правильных ответов из 16 против 8 у базы, поэтому рабочие веса сохранены. Проверенные TRAIN-карточки добавлены отдельно в точный локальный справочник; ссылки показываются по запросу. [Протокол, результаты и ограничения](vlm_source/geology_sft_v2_20261027/README.md) доступны вместе с исходными ответами. Справочная доставка не считается улучшением нейронной точности.

Для начала разметки с уже подготовленной выгрузкой CVAT смотрите [README_CVAT_IMPORT.md](README_CVAT_IMPORT.md).

Для автоматической подготовки разметки из послойного описания и фотографий смотрите [README_EXCEL_JPG_IMPORT.md](README_EXCEL_JPG_IMPORT.md).

Готовое описание экспортируется через `Файл → Сохранить послойное описание (Excel/Word/PDF)…`. Формат Excel закреплён по пользовательскому шаблону с 22 физическими колонками и двумя строками заголовка. Правила заполнения описаны в [FINAL_EXCEL_EXPORT_RU.md](FINAL_EXCEL_EXPORT_RU.md). Word и PDF пока используют прежнюю печатную форму.

Перед итоговой выгрузкой откройте `File → Заполнить паспорт итогового Excel…` или нажмите правой кнопкой на скважине в левой панели. В форме специалист вводит общие сведения о скважине, смещение ГИС, проходку и вынос, а в таблице долблений — номер и границы каждого интервала отбора. Общий интервал вычисляется по введённым долблениям. Номер долбления в Excel меняется на их границе. Значения сохраняются с проектом.

Минимальная PySide6-основа нового интерфейса Kern Analyzer.

Для запуска одним двойным щелчком используйте единственный ярлык `ЗАПУСТИТЬ Kern_Analyzer.lnk` в корне проекта. Он запускает актуальный `launch_latest.py`: проверяет окружение и встроенный финальный справочник, затем открывает приложение. Для подготовки и разметки файл модели не нужен. Старые BAT/CMD и копии предыдущих сборок в проекте не используются.

## Подготовка модели на другом компьютере

Откройте **«Модель → Подготовка модели и перенос…»**. В одном окне доступны справочник, поиск фаций, количество отмеченных примеров, проверка независимости фото и экспорт. **«Экспорт заготовки»** сохраняет 92 постоянных класса `код@индекс`, описания из Excel, схему 16 параметров и рецепт обучения. Это спецификация, а не обученные веса. **«Экспорт датасета»** переносит только проверенные примеры с паспортом разбиения. Оба действия доступны без модели и GPU.

Для финальной модели неизвестные старые метки нужно явно сопоставить справочнику в карточке слоя. Код с несколькими индексами не сопоставляется автоматически. Чтобы включить слой в обучение, отметьте **«Фация и границы проверены»**. Импорт Excel и простое перемещение вершины сами по себе не подтверждают класс и контур. Ранее импортированные разметки с отметкой проверки рекомендуется пересмотреть.

На рабочем ПК подключите свою модель `.pt` через **«Модель → Выбрать модель сегментации…»**. Локальные старые веса не выбираются автоматически. Подробности переноса, команды проверки и обучения: [MODEL_GUIDE.md](MODEL_GUIDE.md).

## Переносимая версия `.exe`

Для другого компьютера используйте папку со сборкой, а не исходный код. В ней
запускается `Kern_Analyzer.exe` и Python отдельно не нужен. Все созданные проекты
и дообученные модели сохраняются рядом с программой в `Kern Analyzer Data`, поэтому
их не затронет обновление самой программы.

Переносимую сборку можно получить через GitHub: загрузите проект в репозиторий, откройте вкладку **Actions**,
  выберите **Build Windows application** и нажмите **Run workflow**. После
  завершения скачайте артефакт `Kern_Analyzer-Windows`, распакуйте его и запускайте
  `Kern_Analyzer.exe`.

Для локальной технической сборки используется `python -m PyInstaller Kern_Analyzer.spec`; отдельного пользовательского BAT-запускателя в проекте больше нет.

При отправке тега вида `v2.0.0` GitHub также создаёт постоянный Release с
файлом `Kern_Analyzer-Windows.zip`. Его можно скачать по адресу
`https://github.com/andrei434566-rgb/CV-1/releases/latest/download/Kern_Analyzer-Windows.zip`.

Публичная переносимая сборка использует CPU-версию PyTorch, поэтому помещается
в лимит одного файла GitHub и запускается без Python. Она подходит для импорта,
разметки, подготовки датасета и проверки модели на CPU. CUDA-дообучение выполняется
из исходного проекта на компьютере с NVIDIA по инструкции `MODEL_GUIDE.md`.

На другой ПК нужно переносить всю распакованную папку сборки, а не только один
`.exe`: PySide6, YOLO и остальные библиотеки находятся в соседней папке `_internal`.
Свою модель `.pt` выберите в приложении отдельно.

Либо запуск из PowerShell:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
```

Сейчас доступны полноэкранная рабочая область с Miro-сеткой, фотографии в сетке по 20 в строке с ручным перемещением и `Разметка → Детекция и сегментация`.

Через **File → Загрузить фото/PDF…** можно добавить изображения или PDF: каждая страница PDF будет преобразована в отдельное изображение для разметки. Полученные страницы хранятся в `projects/pdf_pages`.

После успешного дообучения готовая модель сохраняется в понятную папку `models/trained/<название проекта>/<дата-время>/`. В ней лежат `best.pt`, `facies_catalog.json`, `data.yaml` и `training_info.json`.

Сегментация использует CUDA при наличии, иначе CPU. Дообучение требует CUDA; экспорт и подготовка доступны без неё. Во время сегментации и дообучения появляется окно с текущим файлом или номером эпохи.

При сохранении проекта исходные фотографии копируются в его папку `images/`. После дообучения сохраняется кандидат и отчёт качества по классам. Он не заменяет выбранную модель и ручную разметку автоматически. Контроль `val` используется для выбора эпохи; для окончательной оценки нужны дополнительные независимые скважины, не участвовавшие в подборе.

Большие поступления через «Загрузить фото/PDF» обрабатываются партиями по 24 файла, а для отображения используются рабочие превью с максимальной стороной 1600 px; это ограничивает расход оперативной памяти. Исходные файлы остаются в проекте.

Для фото с интервалом в имени вида `Р-25_2984,00-2986,95.jpg` границы полигона и глубины слоя синхронизированы: изменение верхней или нижней границы полигона меняет цифры интервала, а изменение цифр интервала вертикально изменяет подсветку полигона. Для Excel-импорта шкала хранится отдельно для каждой колонки керна в фотографии.

При сегментации используется явно выбранная пользователем модель. После обработки всех фото справа от сетки появится общий столбик в порядке загрузки; подсветки фаций показаны и на отдельных фото, и в столбике.

## Отдельный этап столбиков керна

В новом маршруте предварительно определяются физические столбики, затем **ваш YOLO `best.pt`** выделяет реальные полигоны слоёв. **Qwen** получает вырезки полигонов и назначает черновые описания и фации. Покрытие и пересечения проверяются отдельно. Если YOLO не нашла фациальных масок, найденные рамки столбиков всё равно собираются в общий керновый столбик, а локальная Qwen описывает каждый целиком. Эти рамки не подменяют фациальные маски и не становятся обучающими парами. Если YOLO нашла часть слоёв, оставшиеся пропуски остаются замечаниями; эвристическая нарезка и справочное назначение фаций для новых фото отключены. Показ колонки и экспорт не объединяют разные полигоны с одинаковыми текстами.

Любой слой можно поднять или опустить на одну позицию: откройте его параметры правой кнопкой на исходном фото или в собранном столбике и используйте **«↑ Слой выше» / «↓ Слой ниже»**. Те же команды доступны по правой кнопке в дереве проекта. Порядок сохраняется вместе с проектом; для привязанных глубин интервалы пересобираются вплотную, без пустых промежутков.

Финальный справочник `Фации_и_литотипы_исправлено_по_новым_фото.xlsx` встроен в приложение: 93 исходных варианта сгруппированы в 92 пары «код + индекс» (у Lms один индекс и два варианта написания). Исходные определения сохранены. Коды различают регистр, например DWCH и DWCh. Справочная характеристика в отчёте отделена от наблюдённых 16 литологических параметров. Визуальные подсказки параметров принимаются человеком в карточке слоя, а не подставляются как факты.

В меню **«Столбики»** можно проверить и поправить границы на фото, выбрать готовую отдельную модель или обучить её. В обучение попадают только фото, где границы были явно подтверждены интерпретатором; минимум — 3 фото. До первого обучения автоматически используется детерминированный детектор.

При выборе другой фациальной модели приложение сразу предлагает переразметить все фото. Эту же операцию можно запустить позже через **«Модель → Переразметить фации…»**. Границы столбиков сохраняются, а текущие фациальные маски, включая ручные правки, заменяются после явного подтверждения.

Дисбаланс частот фаций внутри одной скважины считается естественным. Проверка датасета покажет его как предупреждение, но не будет блокировать дообучение.

Режим **«Макс. эпох → авто»** даёт эвристический ориентир по маскам, фото, скважинам, классам и качеству разметки; число эпох не является гарантией точности. Экспорт всегда разделяет независимые фото, по возможности — скважины; точные копии одного изображения не допускаются в разных частях. Если независимый контроль сформировать нельзя, нужно добавить фотографии, а не разделять вырезки одного фото. Естественный дисбаланс не блокирует обучение; ограниченное повторение редких классов применяется только к обучающей части, контроль остаётся с исходными частотами.

Управление доской:

- перетаскивание фотографии — левой кнопкой мыши;
- перемещение по бесконечной доске — зажатым колёсиком мыши;
- масштаб — колесом мыши;
- удалить выбранное фото — `Delete` или `Backspace`;
- вернуть последнее удалённое фото — `Ctrl+Z`;
- показать все объекты — `Ctrl+0`.

## Обучение на другом компьютере

Откройте **⚙ → Обучение: фото + Excel, теория, YOLO…**. Для пар фото–Excel выберите таблицу и папку JPG, проверьте сопоставление глубин, затем откройте карточки слоёв и подтвердите правильные контуры и исходные описания. Кнопка «Собрать проверенные пары» сохраняет локальные вырезки и `photo_excel_approved.jsonl`. Непроверенные маски и слои без описания пропускаются. «Дообучить Qwen на парах» запускает локальный CUDA Python и оставляет результат кандидатом в `vlm_models/pairs/`; активный адаптер не заменяется сам.

Теоретические PDF, DOCX, TXT, MD и Excel добавляются папкой для локального поиска ассистента. Для отдельного текстового LoRA загрузите `.xlsx` или `.csv` с двумя колонками **Вопрос** и **Ответ**; результаты сохраняются в `vlm_models/theory/`. После проверки кандидата выберите его в настройках ИИ в поле «Текстовый LoRA для чата»; визуальный адаптер описаний остаётся отдельным. Свободный текст не превращается автоматически в пары с вымышленным правильным ответом. Для локального обучения нужны Python с CUDA PyTorch, `transformers`, `peft`, `Pillow` и локальная базовая Qwen3-VL-2B; укажите Python и базу в настройках ИИ. Скрипт запускается с отключённым доступом к Hugging Face и не скачивает модель.

В приложение включены краткие русскоязычные справочные карточки по литологии, осадочным структурам и биотурбации с адресами первоисточников. Они доступны локальному поиску без пары «фото–Excel». Если фото прикреплено к чату, общий теоретический вопрос всё равно направляется в текстовый чат; вопросы о конкретном снимке направляются в визуальный анализ. Новый текстовый LoRA хранится отдельно от адаптера описания фото и включается только после сравнения с базовой моделью на отложенных вопросах.

Для сегментации в том же окне выберите локальную предобученную YOLO `.pt` задачи `segment`. Затем импортируйте следующие фото и Excel, исправьте и подтвердите контуры. Кнопка обучения создаст новую копию YOLO и отчёт; исходная `.pt` сохраняется. Одни интервал и описание из Excel не являются проверенной пиксельной маской. Качество моделей оценивайте по отложенным скважинам; сам факт завершения обучения не означает заданную точность.

## Фото прямо в чате

Кнопка **«Добавить файл»** принимает фото, `best.pt`, Excel и документы. Фото видно в прокручиваемой переписке; ширина меняется левой границей или кнопкой **«Шире»**. Если подключён `best.pt`, новое фото добавляется в проект и проходит YOLO → Qwen. Без него доступно обсуждение целого снимка без автоматических масок. Автоматический результат остаётся черновиком и не попадает в обучение. Для учебной пары CV-1 нужно отдельно подтвердить границы/фацию и описание; последующая правка отменяет пригодность старого подтверждения текста.

## Основной Excel фаций и обучение по фото

В **⚙ → Обучение: фото + Excel, теория, YOLO…** можно выбрать отдельные снимки или целую папку и сопоставить их с послойным Excel. Сопоставление скважины и глубин показывается специалисту до импорта. Приложение создаёт проект с предварительными контурами и переносит в карточки слоёв описания и адреса строк Excel. Наведение на маску фото или слой в собранном столбике показывает описание, глубину и источник.

Если снимок уже прикреплён в чате, кнопка **«Сопоставить это фото с Excel для обучения»** открывает тот же импорт сразу для этого снимка.

Таблица **со всеми фациями** подключается отдельно кнопкой **«Загрузить Excel со всеми фациями…»** в том же окне или через меню **«Модель»**. Для неё нужны заголовки «Код фации», «Индекс фации» и «Название фации» (допускается таблица с кодом и названием без индекса). После импорта её классы становятся основными для выбора фации и следующего датасета YOLO; копия справочника сохраняется с проектом и с моделью. Его можно добавить позже на другом компьютере. Ранее сохранённые метки не переименовываются автоматически: несовпадающие классы показываются на проверке выборки.

Для обучения Qwen нужны проверенные пары фото с описанием. Для обучения YOLO нужны дополнительно проверенные контуры: откройте карточку слоя, исправьте фацию и границы и отметьте **«Фация и границы проверены»**. Затем используйте **«Собрать проверенные пары»** и **«Дообучить Qwen на парах»** либо **«Обучить на проверенных контурах»** для YOLO. Excel сам по себе не подтверждает пиксельные границы и не запускает обучение автоматически.
