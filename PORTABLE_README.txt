KERN ANALYZER — ПЕРЕНОСИМАЯ WINDOWS-СБОРКА

CV-1: фото -> ваш best.pt (полигоны) -> локальная Qwen3-VL-2B
с выбранным LoRA или без него -> проверка геологом -> итоговый Excel.
Подробная настройка: CV1_ARCHITECTURE_RU.md рядом с программой.
В чат можно добавить best.pt и фотографии. По умолчанию выбран режим
базовой Qwen; старые адаптеры автоматически не включаются.

CPU-версия:
1. Полностью распакуйте Kern_Analyzer-Windows.zip в обычную папку.

GPU-версия CUDA 12.6:
1. Скачайте все четыре части: part1.zip, part2.zip, part3.zip и part4.zip.
2. Распакуйте все четыре части в одну и ту же папку. При правильной распаковке
   файлы из всех частей окажутся внутри одной папки Kern_Analyzer.

После распаковки запустите Kern_Analyzer.exe. Не переносите один EXE отдельно:
папка _internal обязательна.

Для интерфейса, разметки и YOLO отдельный Python не требуется.
Для Qwen укажите локальный Python с CUDA и локальную базу в настройках ИИ;
веса и эта среда не включены в EXE. OCR русского и английского текста
включён в сборку. Веса модели фаций намеренно не встроены: выберите свою .pt
через меню «Модель». Проекты и результаты сохраняются рядом с программой в
папке «Kern Analyzer Data».

CPU-релиз работает без NVIDIA. GPU-релиз включает PyTorch CUDA 12.6 и может
использовать совместимую видеокарту NVIDIA для распознавания и дообучения.
Если драйвер или видеокарта несовместимы, используйте CPU-релиз.
