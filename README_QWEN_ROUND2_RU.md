# Раздельное локальное обучение Qwen: 25.10.2026

Этот этап продолжает эксперимент после [непринятого смешанного кандидата](QWEN_SOURCE_PILOT_2026-10-23.md). Создаются два отдельных адаптера от исходной локальной Qwen3-VL-2B-Instruct: для исходных классов фото и для русских теоретических ответов с обычным диалогом. Они не объединяются автоматически и не устанавливаются как рабочая модель без содержательной проверки.

Эти два прохода и дополнительный контроль с четырьмя эпохами завершены: [результаты и решения о непринятии](QWEN_ROUND2_RESULTS_2026-10-26.md). Содержательная проверка не подтвердила пригодность кандидатов для рабочего геологического чата.

## Визуальный этап

- 1 320 учебных фото: по 120 на каждый из четырёх исходных классов Mendeley и семи классов чистого DCID-512-7.
- Те же 88 проверочных фото, что в первом эксперименте. Их состав и порядок проверены по ID и побайтово; прежние 60 фото каждого класса входят в новые 120.
- Mendeley заново разделён по скважинам; DCID не содержит подтверждённых идентификаторов скважин. Проверены исходные и фактические пиксельные хеши. Test нового подготовленного разбиения не используется. Исходные папки Mendeley train/val/test перегруппированы по скважинам, поэтому прежнее утверждение об исключении всех исходниковых test-файлов было неточным. Из 480 выбранных Mendeley train-фото 361 происходит из исходного train, 65 — val, 54 — test; проверочные скважины нового разбиения остаются отдельными.
- Один проход, learning rate `3e-5`, language-only LoRA rank 8 q/v, batch 1, накопление за 4 примера, фото до 280 px. Новый набор не содержит подробных описаний и фациальных меток.

Подготовка выполняется существующим `scripts/prepare_qwen_source_pilot.py --write --train-per-class 120 --val-per-class 8 --seed 20261022`. В обучение подаётся **`train_visual.jsonl`**, не `mixed.jsonl`.

## Теория и общение

После проверки и удаления двух повторённых вопросов:

- 181 ранее подготовленная теоретическая пара из исходных 183;
- 48 новых коротких QA по 12 прочитанным источникам;
- 3 текстовых QA, ограниченных опубликованным разрезом Ямала из статьи ТПУ 2025 года;
- 60 авторских разговорных пар для сохранения уместного обычного общения;
- всего **292 учебные пары**, полностью без изображений;
- отдельно **37 вопросов по теории и 12 разговорных запросов**. Это проверка перефразировок и регрессий: темы и статьи местами общие с обучением, независимым экзаменом по новым знаниям она не является.

Новые материалы: IODP/ODP, BGS, NOAA, Kansas Geological Survey, университетские учебные материалы и ТПУ. Для исправления двух старых ответов о пятнистости прочитан IODP Technical Note 5 (2023), в том числе страницы 43, 45 и 52. Отдельный видимый ход не сделан обязательным условием полной биотурбационной переработки.

Подготовка удаляет нелепое начальное «да/нет» у открытого вопроса, сохраняя остальные факты; исправления, исходные ответы, источники и контрольные суммы записываются в журнал. Два одинаковых учебных вопроса сохраняются только в первом варианте. Исходные файлы прежней теории не меняются. `training_approved` означает разрешённую для этого эксперимента пару, а `geology_approved=false` явно сохраняет отсутствие подтверждения специалистом.

Источники, короткие русские пересказы, исправления и разговорные пары лежат в [`vlm_source/theory_round2`](vlm_source/theory_round2). Там же отдельно сохранены сведения о трёх будущих визуальных источниках. MAT с 711 фото оставлен вне обучения: соответствие числовых ID названиям пород и группы физических образцов не установлены. Фотопанели российской статьи остаются кандидатами; их вырезки и глубинные метки не создавались.

## Повторить текстовый этап

Из корня репозитория:

```powershell
python scripts/prepare_qwen_theory_round2.py `
  --new-theory-train vlm_source/theory_round2/train.jsonl `
  --new-theory-holdout vlm_source/theory_round2/holdout.jsonl `
  --additional-theory-train vlm_source/theory_round2/case_study_russia_train.jsonl `
  --additional-theory-holdout vlm_source/theory_round2/case_study_russia_holdout.jsonl `
  --answer-overrides vlm_source/theory_round2/overrides.json `
  --output-dir open_datasets/qwen_theory_round2_20261025 --write
```

Без `--write` выполняются только проверки. Существующая папка не перезаписывается. Дополнительные источники задаются повторением `--additional-theory-train` и `--additional-theory-holdout`; правила разделения и происхождения действуют для каждого файла.

```powershell
$taskPython = '..\vlm_core_v1\.venv\Scripts\python.exe'
$taskBase = '..\vlm_core_v1\model_cache\hub\models--Qwen--Qwen3-VL-2B-Instruct\snapshots\89644892e4d85e24eaac8bacfd4f463576704203'
& $taskPython -u scripts/train_qwen_source_pilot.py `
  --manifest open_datasets/qwen_theory_round2_20261025/mixed.jsonl `
  --eval-manifest open_datasets/qwen_visual_round2_20261025/val_visual.jsonl `
  --val-text-manifest open_datasets/qwen_theory_round2_20261025/holdout_theory.jsonl `
  --val-conversation-manifest open_datasets/qwen_theory_round2_20261025/holdout_conversation.jsonl `
  --system-prompt-file open_datasets/qwen_theory_round2_20261025/system_prompt.txt `
  --model $taskBase --epochs 2 --learning-rate 0.00002 --theory-limit 37 `
  --output-dir ../vlm_core_v1/outputs/core_vlm_theory_round2_20261025_lora
```

Нужны локальная CUDA-среда и модель. Обучение и генерация работают с запретом сети. Классификационные фото здесь используются только для проверки визуальных регрессий, а не для обучения текстового адаптера. Перед загрузкой второго адаптера первый процесс должен завершиться и освободить видеопамять.

Сохраняются исходные ответы до/после, матрицы ошибок, параметры и хеши. Снижение loss, непустой ответ или закрытая классификация с перечисленными вариантами не доказывают правильность полного описания керна. Для принятия кандидата нужны содержательная проверка теории, сохранение обычного диалога и отдельные проверенные реальные скважины.

До просмотра ответов текстового кандидата закреплена [рубрика всех 37 вопросов](vlm_source/theory_round2/evaluation_rubric.json): ключевые факты, существенные ложные утверждения, допустимая неопределённость и отдельный учёт обрывов. Её категории не выдаются за экспертную геологическую точность.
