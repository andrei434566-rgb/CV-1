# Перенос Kern Analyzer на другой ПК

Репозиторий `CV-1` содержит исходники приложения. Релиз
`cv1-workspace-v1` содержит переносимый Windows EXE, базовую
`Qwen3-VL-2B-Instruct`, все сохранённые LoRA-адаптеры, две модели YOLO и
локальный геологический справочник. Исходные фото, Excel, внешние учебные
архивы и виртуальное окружение не включены.

Файлы релиза: https://github.com/andrei434566-rgb/CV-1/releases/tag/cv1-workspace-v1.
Для установки подготовьте около 25 ГБ свободного места: загружаются модели,
приложение, Python и CUDA-библиотеки.

1. Войдите в GitHub и клонируйте приватный репозиторий как папку
   `kern_analyzer_app` внутри новой папки проекта, например:
   `git clone https://github.com/andrei434566-rgb/CV-1.git kern_analyzer_app`.
   Можно скачать ZIP репозитория и переименовать распакованную папку в
   `kern_analyzer_app`.
2. Из PowerShell в папке `kern_analyzer_app` запустите
   `powershell -ExecutionPolicy Bypass -File .\transfer\install_cv1.ps1`.
   Скрипт попробует скачать файлы приватного релиза через сохранённый вход
   GitHub. Если входа для Git нет, скачайте файлы релиза браузером в
   `transfer\downloads` и повторите команду.
3. Скрипт проверит SHA256, соберёт модель из частей, создаст соседнюю папку
   `vlm_core_v1`, распакует приложение и поставит Python/CUDA-библиотеки для
   локальной VLM. После этого запустите `Kern_Analyzer.exe`.

Первый запуск установки требует интернет для скачивания файлов релиза и
Python-библиотек. Само приложение и модель после установки работают локально.
Базовая Qwen3-VL-2B-Instruct распространяется по Apache-2.0; источник модели:
https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct.

Адаптер `core_vlm_v8_single_column_lora` используется по умолчанию для фото.
Остальные адаптеры сохранены как экспериментальные; справочные адаптеры v4
не включаются автоматически, поскольку не прошли геологическую проверку.
