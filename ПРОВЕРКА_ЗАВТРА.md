# Проверка CV-1 и VLM на Windows

1. Скачайте Code -> Download ZIP и распакуйте проект.
2. В PowerShell внутри папки проекта выполните:
   powershell -ExecutionPolicy Bypass -File ".\Установить_VLM.ps1"
3. Дождитесь скачивания модели. Нужны интернет, свободное место на диске, NVIDIA GPU с CUDA и установленный Python 3.11.
4. Установите основные зависимости приложения:
   py -3.11 -m pip install -r requirements.txt
5. Запустите приложение:
   py -3.11 run.py
6. В окне «Настройки -> Настроить помощника и папки» проверьте:
   Python VLM: соседняя папка vlm_core_v1\.venv\Scripts\python.exe
   Qwen3-VL-2B: папка snapshot с config.json в vlm_core_v1\model_cache\hub\models--Qwen--Qwen3-VL-2B-Instruct\snapshots
   LoRA: оставьте пустым, если обученные веса не скачаны.
7. Отправьте в чате ИИ-ассистента короткий вопрос, затем проверьте описание фотографии.
8. Загрузите фото и отдельную YOLO-модель сегментации .pt для проверки сегментации.

Ограничения:
- ZIP GitHub не содержит веса Qwen и обученный LoRA. Скрипт скачивает только открытую базовую модель.
- Установщик VLM требует совместимую NVIDIA GPU и рабочую установку CUDA PyTorch.
- Если VLM не запускается, проверьте сообщение об ошибке; полная совместимость с конкретным компьютером не проверена.
- EXE не обновлён; тестируйте Python-исходники.
