# Кандидат v3 с новыми интернет-фото

**Статус: отдельный исследовательский кандидат, не продвинут.** На повторно используемых 50 проверочных фрагментах UniBo — **29/50 (58%), macro-F1 0,58670** против 27/50, 0,55653 у v2. Плохо дренируемая пойма остаётся 2/8 и не достигает предварительного порога 3/8. Настройки приложения и стандартный исследовательский выбор v1 не изменены.

Обучение: прежние 704 фрагмента плюс 24 новые вырезки из четырёх фотопанелей двух источников. Из них 12 продельтовых из Австралии, 6 русловых из Китая и 6 общих пойменных без метки типа дренирования. Для последних обучается сумма A+B, без принудительного назначения A либо B. Веса исходной Qwen, её язык и энкодер не менялись.

При удержании целых новых источников OOF-результат — лишь 7/24 допустимых ответов; перенос остаётся слабым. Финальный классификатор обучен и на этих источниках, поэтому они не являются его независимым внешним тестом. Точность на 92 фациях и новых скважинах пользователя не установлена.

Веса и нормализатор — `facies_head.safetensors`, 295 408 байт, SHA256 `63a4e09255f2bf03cfd49c9d0849c856c16fcb76ef324994ae31298e9f63ce78`. Переносите каталог целиком. Нужна точная исходная HF-база Qwen3-VL-2B из `MODEL_CONTRACT.json`, CUDA и библиотеки проекта. База, фото и кеши сюда не включены. Это линейный классификатор на визуальных признаках, а не LoRA или `best.pt` сегментации.

Из корня репозитория для одной заранее вырезанной области керна:

```powershell
python scripts/classify_with_qwen_facies_head.py --model-dir research_models/web_partial_qwen_facies_head_v3_candidate --base "D:\models\Qwen3-VL-2B-Instruct" --core-crop "D:\core\interval.png" --output-json "D:\results\interval.json"
```

Офлайн-команда проверяет SHA256, выдаёт русский исходный класс и некалиброванные численные оценки. Неизвестные фации не отвергаются; автоматического соответствия 92 фациям нет. Генерации подробного описания и сегментации ящика здесь нет. Кандидат использует совместимый контракт признаков v2 (`qwen_post`), но другой способ обучения выходных коэффициентов.

Свежая проверка загруженных весов совпала с сохранёнными численными оценками. При первой попытке полная база получила Windows1455 при отображении файла в память, повторный отдельный запуск прошёл. Для загрузки важна доступная системная память Windows, а не только VRAM; подробности сохранены в `portable_smoke.json`.

`research_metrics.json` — метрики; `selection_frozen.json` — выбор восьми вариантов только по train; `acceptance_review.json` — независимая перепроверка; `PROVENANCE.json` — происхождение и параметры.
