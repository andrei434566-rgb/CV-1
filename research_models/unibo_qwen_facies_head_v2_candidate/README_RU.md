# Кандидат v2: шесть фаций на замороженных признаках Qwen

**Статус: не продвинут, два заранее заданных условия не выполнены.** Сохранён для воспроизводимого исследования. Стандартная исследовательская команда по-прежнему выбирает v1; приложение не подключает этот каталог автоматически.

Обучен классификатор на 704 учебных фрагментах из 49 исходных фотографий UniBo, 21 S-группа. Удвоение числа фрагментов не означает удвоение независимых геологических данных. Три группы продельты остаются теми же. Выбран по трём разделениям целых учебных S-групп из 32 вариантов. Признаки — 4096 значений после merger исходной Qwen3-VL-2B; веса классов равные, ridge lambda 1. Языковые и визуальные веса Qwen заморожены.

На прежней повторно используемой выборке разработки: **27/50 (54%), macro-F1 0,55653** против 26/50 (52%), 0,48613 у v1. Продельта 2/10 вместо 1/10; плохо дренируемая пойма 2/8 вместо 3/8, русловой песок 9/12 вместо 11/12. Минимум 28/50 и сохранение поймы не достигнуты. Это результат шести классов источника на трёх коррелированных S-группах, не точность CV-1 на новых скважинах.

Переносите каталог целиком. Веса и нормализатор — `facies_head.safetensors`, 295 408 байт. SHA256 указан в контракте и аудите. Требуется исходная HF-база Qwen3-VL-2B точной ревизии и SHA256 из `MODEL_CONTRACT.json`, CUDA и библиотеки проекта. Базовые веса, исходные фото и кеш признаков не включены. Пакет не является LoRA, моделью сегментации `best.pt` или генератором подробных описаний.

Из корня репозитория для одной **заранее вырезанной однородной области керна**:

```powershell
python scripts/classify_with_qwen_facies_head.py --model-dir research_models/unibo_qwen_facies_head_v2_candidate --base "D:\models\Qwen3-VL-2B-Instruct" --core-crop "D:\core\interval.png" --output-json "D:\results\interval.json"
```

Команда работает локально без скачивания, проверяет веса/контракт и возвращает русский класс с численными оценками и статусом приёмки. Оценки не калиброваны как вероятность; неизвестные фации не отвергаются. Соответствие 92 фациям проекта не установлено. Целый ящик эта команда не сегментирует.

[Полный протокол и результат](../../VLM_HEAD_GROUPCV_2026-10-30.md). `selection_frozen.json` содержит результаты выбора по учебным группам; `acceptance_review.json` — независимую перепроверку и проваленные условия. `research_metrics.json` и `PROVENANCE.json` сохраняют метрики и происхождение. Экспертной приёмки ещё нет.
