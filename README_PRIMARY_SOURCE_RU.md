# Основной источник для фаций и гидродинамического режима

На нужном компьютере откройте **⚙ справа сверху → Основной источник…**.
Нажмите **Выбрать материалы…**, выберите один или несколько проверенных файлов,
затем **Подключить**. Поддерживаются DOCX, XLSX/XLSM, текстовый PDF, TXT,
Markdown, CSV и TSV. Для PDF-сканов без текста потребуется OCR.

Приложение сохраняет локальные копии и создаёт справочный индекс. Материалы
остаются доступны после перезапуска и отключения исходной флешки. Исходники
не отправляются в интернет и не публикуются в GitHub. На другом ПК подключите
свои материалы через тот же пункт меню. «Отключить основной источник» снимает
приоритет, сохраняя документы на диске.

В описании одиночного интервала, целого столбика и пакета фотографий подходящие
фрагменты передаются локальной Qwen в первую очередь для двух полей:

- фация — терминология и диагностические критерии вашего справочника;
- гидродинамический режим — гипотеза по структурам и критериям материала.

Та же настройка учитывается в вопросах чата про фации и гидродинамику. Общий
справочник приложения не заменяет выбранные определения. При этом цвет,
литология и текстура должны соответствовать фотографии. Пример породы из
документа сам по себе не доказывает, что эта порода присутствует на фото.
Если диагностических признаков мало или критерии противоречат друг другу,
ответ должен сохранять неопределённость. Проверенная поправка специалиста
для конкретного интервала имеет приоритет над общими материалами.

Режим виден и редактируется в карточке интервала; при экспорте он включается
в краткое описание Excel. С результатом сохраняются названия, контрольные
суммы документов и указатели использованных фрагментов. Смена источника
не использует прежний ответ из кеша для новых запросов.

Подключение работает как справочная доставка контекста, **без изменения весов**.
Это позволяет применять свои правила сразу, без нового обучения. Оно не
гарантирует правильность интерпретации: проверка на собственных независимых
скважинах остаётся необходимой. Материалы ограниченно выбираются по текстовому
соответствию запросу; весь справочник целиком в каждый запрос не вставляется.

Уже сохранённые описания автоматически не переписываются. Для новой
интерпретации используйте повторное описание; подтверждённые правки специалиста
сохраняются. Веса можно отдельно дообучать через окно «Обучение».

Локальные версии источников хранятся в `primary_reference` пользовательской
папки приложения. Импорт принимает до 20 документов по 100 МБ, до 2 млн
символов текста из каждого; предупреждения о непрочитанных страницах и
сокращённом импорте выводятся после подключения.
