# Обучение по папке фото и одному Word

Откройте меню **⚙ справа сверху → Обучение…**. В отдельном светлом окне
выберите **Фото + Word**. Основная рабочая область керна остаётся на месте.

1. Сложите фотографии в папку и назовите их `0001.jpg`, `0002.jpg`, `0003.png`.
2. Создайте один `Описания.docx`. Перед каждым описанием напишите номер:

   ```text
   Фото 0001
   Песчаник серый, мелкозернистый, с тонкой косой слоистостью.
   Контакты преимущественно чёткие.

   Фото 0002
   Алевролит тёмно-серый, тонкослоистый, с прослоями аргиллита.
   ```

3. Выберите **Папка фото…**, затем **Word…** или **Папка Word…**. Если в папке
   несколько Word-файлов, приложение предложит выбрать один.
4. Нажмите **Проверить пары**. Выберите строку, чтобы увидеть фото и полный
   текст. Исправьте ошибки в исходниках и проверьте повторно.
5. Отметьте, что описания и номера проверены специалистом, и нажмите
   **Подготовить проверенные пары**. Ошибочные пары и фото без описания
   пропускаются; их причины сохраняются в отчёте подготовки.
6. Нажмите **Начать локальное обучение на этих парах**. Новая версия модели
   сохраняется отдельно; рабочая модель автоматически не заменяется.

Можно копировать текст и таблицы из Excel прямо в Word. Сохраняются несколько
абзацев, переносы строк, длинные тексты и порядок разделов. Изображения в Word
вставлять не нужно. Поддерживается `.docx`; старый `.doc` сначала сохраните как
`.docx`. Заголовки `Фото № 0001`, `Фото 0001.jpg` и `Фото 0001: описание` также
поддерживаются. Начальные нули не влияют на сопоставление: `Фото 0001` найдёт
`1.jpg`, но не `10.jpg`. Папка фото просматривается вместе с подпапками.

Повторные номера в Word, несколько фото с одним номером, повреждённые фото,
отсутствующие фотографии и пустые описания исключаются. После изменения Word
или фото нужна новая проверка. На подготовке сохраняются копии оригинальных
фотографий и Word, полный текст и контрольные суммы. Файлы не отправляются в
интернет. Локальные учебные данные и новые веса исключены из Git.

Подготовка работает на CPU. Через окно «Обучение» можно использовать пары для
обучения классификатора на проверенных метках. Сохраните кандидат отдельно
и оцените его на фотографиях из независимых скважин.

Описание должно относиться именно к соответствующему фото; для нескольких
разных слоёв укажите их последовательность. Указанные специалистом фации
сохраняются в тексте без выдумывания дополнительных меток. Текст помогает подготовить метки для классификатора. Для обучения YOLO границам нужны отдельно проверенные контуры:
одного общего описания фотографии недостаточно.
