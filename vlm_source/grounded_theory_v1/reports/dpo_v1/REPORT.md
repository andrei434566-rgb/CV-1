# Геологическое DPO-обучение, 27.10.2026

Обучена отдельная языковая LoRA для свежей локальной Qwen3-VL-2B:
72 пары предпочтений (64 геология со справкой и 8 общение), 2 эпохи,
36 шагов за 200.3895 с, LR 5e-6, beta 0,1,
rank 8, q/v-проекции. Предыдущий SFT-адаптер не использовался как старт.

В каждой паре правильному ответу противопоставлен намеренно ложный вариант.
Он используется только как отвергаемый ответ DPO. Эти варианты не являются
справочной истиной и исключаются из обычного SFT и локального поиска.

| Проверка: верно / частично / неверно | База | DPO |
|---|---:|---:|
| 10 вопросов со справкой | 8 / 1 / 1 | 7 / 2 / 1 |
| 4 вопроса без справки | 0 / 0 / 4 | 0 / 0 / 4 |
| 4 реплики общения | 4 / 0 / 0 | 4 / 0 / 0 |

Совпадения по 8 исходным классам фото: база
2/8, DPO 2/8.
Это маленькая регрессионная проверка исходных классов, а не фаций керна.

Решение: `rejected_for_general_assistant`. Улучшения вопросов со справкой нет: 8 правильных ответов у базы против 7 у DPO. Сохраняются основные геологические ошибки; ответ об отсутствии данных для пористости дополнен неподтвержденными условиями измерения.
Рабочая модель приложения не заменена. Веса адаптера сохранены локально отдельно.
Точные строки ответов совпадают в 17
из 18 проверенных текстовых пар;
изменены ответы: gval_09_missing_porosity.

Базовые ответы повторно использованы из grounded-SFT после строгой проверки
совпадения модели, оценочных входов и параметров генерации, версий и SHA256.
Учебный набор отличается; он не входит во входы неизменённой базовой модели.
Происхождение сохранено в `baseline_reuse.json`.

Оценка сделана ассистентом вслепую, затем раскрыт ключ A/B; геолог не проверял.
Повторно использованы вопросы разработки. Рецепт выбран после предыдущего SFT;
это не независимый новый тест. Loss не означает геологическую accuracy, а данный
опыт не доказывает качество фотографических описаний или 95% распознавания.

`dpo_result.json` содержит отдельные группы, категории ошибок, объяснения,
рецепт и SHA весов. Сырые ответы, включая **ошибки**, сохранены для аудита.
Они не являются фактами и не должны становиться положительными учебными целями.
Фото и бинарные веса сюда не включены.
