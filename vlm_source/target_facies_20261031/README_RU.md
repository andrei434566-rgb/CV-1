# Поиск точных фото продельты и плохо дренируемой поймы

Проверка 31.10.2026. Ниже различаются скачанные фотографии, справочные материалы и найденные, но недоступные иллюстрации. Это не утверждение о просмотре всего интернета.

| [Chengjiang, Saleh et al., 2022](https://doi.org/10.1038/s41467-022-29246-z), CC BY 4.0 | [Оригинальный PDF](https://www.nature.com/articles/s41467-022-29246-z.pdf) скачан. Рис.2i/j: 7 вырезок массивных глинистых пород продельтовых потоковых отложений. Подписанные биотурбированные гемипелагические прослои исключены. Панели не имеют опубликованных отдельных глубин. |
| [Nakdong, Jeong et al., 2022](https://doi.org/10.3390/app12010177), CC BY 4.0 | [Оригинальный PDF](https://mdpi-res.com/d_attachment/applsci/applsci-12-00177/article_deploy/applsci-12-00177.pdf) скачан. Рис.2e, керн ND-3, 17,00–17,78 м внутри продельтового Unit D 23,50–15,10 м: 4 вырезки. Другие колонки рисунка не выданы за продельту. |
| [Boss Point, Rygel et al., 2015](https://journals.lib.unb.ca/index.php/ag/article/view/21439) | [Оригинальный PDF](https://journals.lib.unb.ca/index.php/ag/article/download/21439/26308/34252) скачан. Текущая карточка статьи указывает CC BY 4.0 с переходом журнала с 01.01.2025; PDF содержит старый copyright 2015. Дата и основание лицензии сохранены отдельно. |

Скачивание только по открытым URL. Авторизация, CAPTCHA и ограничения доступа не обходились. Частные коллекции пользователя и закрытая база DeepCore не использовались.

В манифесте каждой принятой вырезки сохранены DOI, URL, описание на русском по публикации, исходная панель, координаты, интервал/его отсутствие, домен, хеш фото и пикселей, исходный класс и группа. `geologist_approved=false`: источник прочитан и участок локализован, но это не подтверждение специалистом проекта и не автоматическое сопоставление с 92 фациями.

Вырезки одного снимка не считаются независимыми объектами. Все 15 добавлены только в train, прежние 50 val сохранены, закрытый проектный test не открывался. Ограниченная нативная ширина Nakdong и отличие обнажения Boss Point сохраняются в паспортах.
