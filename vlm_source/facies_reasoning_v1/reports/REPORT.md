# Локальное обучение фациальным связям

Qwen3-VL-2B: 484 текстовые учебные строки, включая 70 новых карточек в двух режимах; две эпохи.

| Проверка: верно / частично / неверно / неясно | База | Кандидат |
|---|---:|---:|
| 11 новых фациальных сценариев | 2 / 3 / 6 / 0 | 1 / 6 / 4 / 0 |
| FRV1-09: только исследовательский | 0 / 1 / 0 / 0 | 0 / 1 / 0 / 0 |
| 4 прежних геологических вопроса | 0 / 0 / 4 / 0 | 0 / 0 / 4 / 0 |
| 4 реплики общения | 4 / 0 / 0 / 0 | 3 / 1 / 0 / 0 |

Классы исходных изображений: база 2/8; кандидат 1/8.
Решение: `rejected_for_general_assistant`. На малой слепой проверке ответы стали полнее, но надёжного улучшения геологических рассуждений не показано; обнаружены ошибки в базовых определениях и ухудшение контрольной классификации изображений. Требуются проверенные геологом примеры и отдельная проверка на скважинах.
Активная модель приложения не изменена.

Оценка проведена ассистентом вслепую, без проверки геологом. Новые сценарии — текстовые, их источники и концепции пересекаются с обучением.
FRV1-09 исключён из формального подсчёта. Проверка не измеряет точность фаций по фото или качество на новых скважинах.
Сырые ответы с возможными ошибками сохранены для аудита и не являются материалом для обучения.
