- [Официальный набор](https://www.usgs.gov/data/archive-sediment-data-vibracores-collected-2016-fire-island-new-york) содержит 14 кернов под CC0. Из 30-страничного PDF-журнала извлечены 60 исходных английских описаний по 14 кернам без OCR: `data/external_raw/usgs_fire_island_2016/source_intervals.json`. Для просмотра рядом с фотографиями: `data/external_raw/usgs_fire_island_2016/interval_review.html`.
- Для двух вертикальных фотографий отметки линейки через 10 см привязаны к пикселям вручную. Семь небольших окон и русские черновики только по видимым признакам: `data/usgs_fire_island_vertical_pilot/review.html`. В основном обучающем корпусе этих окон нет (`training_approved=false`).
- На двух окнах v8 создала правильный JSON с данными глубинами, но описала рисунок общими словами и пропустила диагностические тёмные изогнутые прослои. Протокол: `outputs/fire_island_vertical_v8_smoke.json`. По двум примерам нельзя считать процент точности и нельзя вводить новую модель в приложение.
- В `review.html` можно исправить подпись, отметить точные пары и скачать `fire_island_vertical_review.json`. Импортёр `import_fire_island_vertical_review.py` проверяет ID, SHA-256 исходного PDF и каждой вырезки, требует явного подтверждения и имени проверяющего; затем создаёт отдельные `train.jsonl` (P22-C14) и `heldout.jsonl` (P25-C05). Пока экспертный JSON не получен, эти файлы не созданы и обучение на семи окнах не запускается. Даже после проверки это слишком маленькая выборка для оценки качества приложения.
- Добавлены 14 визуально просмотренных кандидатов с трёх горизонтальных фото. Экспериментальная выборка теперь содержит 21 окно из пяти кернов; три керна обучающие, два полностью отложены. Опытная LoRA `outputs/core_vlm_fire_island_structure_v2_lora/` обучена только через `--experimental-candidates`. На восьми отложенных окнах правильный JSON с глубинами улучшился с 2/8 до 8/8, но описания важных изогнутых прослоев остаются неверными. [Карточка с ограничениями](outputs/core_vlm_fire_island_structure_v2_lora/MODEL_CARD.md). В приложение модель не включена.

### USGS Conconully VC4: новые фото с подробным журналом

- [Официальный выпуск USGS](https://www.usgs.gov/data/sediment-computed-tomography-ct-scans-photographs-and-core-log-descriptions-conconully), DOI 10.5066/P14DXYOD, CC0. Загружен исходный PDF VC4 объёмом 643 356 734 байта и CSV первичных описаний; размеры и SHA-256 сохранены в `data/external_raw/usgs_conconully_2025/inventory.json`.
- В шести страницах PDF показаны последовательно 0–323 см керна. Из каждой страницы извлечено отдельное фото без наложенных схем и подписей; исходный текст страницы сохранён дословно в `data/external_raw/usgs_conconully_2025/page_index.json`. Для просмотра вместе с 40 строками исходного CSV: `data/external_raw/usgs_conconully_2025/page_review.html`.
- CSV содержит 27 протяжённых записей и 13 точечных наблюдений. Пять соседних протяжённых записей перекрываются. Строка `conconully_vc4_02` названа сегментом 60–120 см, хотя её числовая глубина 2–60 см; исходная ошибка сохранена и отмечена. В индексе все 40 записей связаны со страницами **только по числовой глубине**, а не с точными пикселями.
- Пока нет проверенных русских визуальных целей и независимого керна VC4 для оценки, **0 записей допущено к обучению**. Фото и подписи нельзя превращать в интервальные обучающие пары автоматическим совпадением по странице. Скрипты: `ingest_usgs_conconully_descriptions.py`, `prepare_usgs_conconully_vc4_review.py`.
- Для показа различимых деталей сделаны [четыре увеличенных фрагмента](data/usgs_conconully_vc4_crop_candidates/review.html) с русскими визуальными черновиками и исходными строками USGS. Глубины получены линейной интерполяцией по целым сегментам PDF, поэтому `interval_pixel_aligned=false`, `training_approved=false`; особенно осторожно следует трактовать цвета и вещество под освещением фото. Генератор: `prepare_usgs_conconully_vc4_crops.py`.
- Качественная проверка одного фрагмента 2,42–2,52 м: v8 и опытная Fire Island LoRA v2 дали дословно одинаковый ответ про неровную влажную поверхность и трещины, пропустив контрастные тёмные и серые полосы. [Протокол](outputs/conconully_vc4_qualitative_diagnostic.json). Это единичный случай без утверждённого геологом эталона, не процент точности; новое дообучение на четырёх окнах одного керна не запускалось.

- [Официальный отчёт USGS SIR 2011-5006](https://pubs.usgs.gov/publication/sir20115006), DOI 10.3133/sir20115006.
