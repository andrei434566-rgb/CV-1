# Русская теория керна, выпуск v5

Это исходные тексты и воспроизводимые входные данные для локального Qwen3-VL-2B. В наборе нет фотографий и фациальных меток. Ответы — короткие авторские пересказы первичных методик IODP, USGS и Большой российской энциклопедии; ссылки и происхождение записаны в `theory_cards_v5.json` и метаданных JSONL.

- `theory_training_v5.jsonl`: 183 текстовые пары «вопрос — ответ», включая прежние v2–v4 и 32 новых варианта v5.
- `theory_holdout_v5.jsonl`: 24 контрольных вопроса, исключённых из обучения, включая 5 новых вопросов v5.
- `theory_cards_v5.json`: 21 новая карточка для локального справочника; 16 использованы в обучении, 5 только в проверке модели.

Карточки проверены по указанным источникам, но **ещё не подтверждены геологом**. Текстовая теория не является доказательством распознавания породы или фации по фотографии. Обученный адаптер v5 проверен на отложенных вопросах и **не принят для приложения**: он сохранил фактические ошибки базовой модели. Подробности — в `model_spec_theory_v5.json`. Рабочее улучшение в этом выпуске — расширенный локальный справочник в приложении.

На другом ПК для повторного обучения нужны базовая модель Qwen3-VL-2B-Instruct и Python-окружение из проекта. Работайте в папке `vlm_core_v1`, используя путь к JSONL из этого каталога:

```powershell
$env:HF_HUB_OFFLINE='1'
$env:TRANSFORMERS_OFFLINE='1'
$env:PYTORCH_CUDA_ALLOC_CONF='max_split_size_mb:64'
.\.venv\Scripts\python.exe .\train_qwen3vl.py --model .\model_cache\hub\models--Qwen--Qwen3-VL-2B-Instruct\snapshots\89644892e4d85e24eaac8bacfd4f463576704203 --manifest ..\kern_analyzer_app\vlm_source\theory_v5\theory_training_v5.jsonl --output-dir .\outputs\core_vlm_theory_v5_lora --epochs 1 --learning-rate 1e-5 --lora-rank 4
```

Для диалога приложение использует общий локальный справочник `app/resources/theory/theory_cards_v5.json`, без интернет-запросов. Ссылки в ответе выводятся только по просьбе пользователя.
