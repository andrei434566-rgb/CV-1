# Локальный ИИ-седиментолог — подготовка данных и обучение

## Что делает программа

`CoreSedTrainer.exe` открывает окно, в котором геолог:

1. выбирает книгу Excel с интервальными описаниями и лист;
2. указывает столбцы глубины «от», «до», описания и, при наличии, обстановки;
3. выбирает папку фотографий керна;
4. проверяет таблицу сопоставленных фото и интервалов;
5. подтверждает пары и запускает дообучение Qwen3-VL через LoRA.

Фото сопоставляются по интервалу глубин в имени файла, например `3841.00-3841.98.jpg`. Программа считает пару пригодной, если описания из Excel перекрывают не менее 80% интервала фотографии. Не сопоставленные снимки и причины попадут в итоговую сводку.

Это экспериментальный инструмент подготовки данных и запуска обучения. Он не обещает заданную точность и не является геологическим заключением. В текущей версии программа сохраняет LoRA-адаптер для последующего подключения к базовой Qwen3-VL; это ещё не отдельное приложение для выдачи производственного отчёта.

## Что нужно на компьютере

- Windows 10/11 x64;
- интернет при первом запуске;
- NVIDIA GPU с 8 ГБ видеопамяти или больше и актуальный драйвер;
- не менее 25 ГБ свободного места в папке результатов;
- Excel `.xlsx` или `.xlsm` и фотографии с глубинами в именах.

Первый запуск сам скачает управляемый Python, CUDA-сборку PyTorch, библиотеки и базовую модель `Qwen/Qwen3-VL-2B-Instruct`. Загрузка может занять время и несколько гигабайт трафика. Сам EXE содержит только интерфейс, скрипт обучения и менеджер Python.

## Запуск

1. Скопируйте `CoreSedTrainer.exe` на обучающий компьютер.
2. Откройте EXE. Если Windows покажет предупреждение о неподписанном приложении, проверьте SHA-256 у отправителя, затем подтвердите запуск в SmartScreen.
3. Выберите Excel, фото и папку результатов.
4. Нажмите «Подготовить пары…», откройте CSV и проверьте, что снимки связаны с правильными строками Excel.
5. Только после проверки поставьте отметку разрешения и запустите обучение.

Файлы Excel и фотографий остаются в исходном месте. Манифест содержит локальные пути и выдержки описаний; его не следует публиковать вместе с исходными данными. В папке результатов будут кэш модели, Python-окружение, журнал сопоставлений и адаптер.

## Сборка EXE из исходников

Нужен Python 3.11 x64 и PyInstaller 6.22.2:

```powershell
python -m pip install pyinstaller==6.22.2
Set-ExecutionPolicy -Scope Process Bypass
.\build_exe.ps1
```

Скрипт скачивает официальный `uv` 0.12.20, сверяет опубликованный SHA-256 и собирает файл в `dist\CoreSedTrainer.exe`. Сборка предназначена для Windows x64. Для GitHub можно публиковать исходники и собранный EXE, но папки с фото, Excel, манифесты и модельные веса в репозиторий добавлять нельзя.

## Выходные файлы

По умолчанию программа использует `Документы\CoreSedimentologist`:

- `data\training_manifest.jsonl` — проверяемые записи для обучения;
- `data\pairs_to_review.csv` — таблица ручной проверки;
- `data\pairing_summary.json` — сводка о сопоставлении;
- `.runtime\` и `.runtime_python\` — Python и обучающее окружение;
- `.uv_cache\` и `model_cache\` — кэш пакетов и базовой модели;
- `models\core_vlm_custom_lora\` — обученный адаптер и метрики.

## Текущие ограничения

- Для подбора используются интервалы глубин из имён файлов. Если фото названы иначе, сначала переименуйте копии или подготовьте имена с диапазоном глубин.
- В одной книге можно выбрать один лист и один набор столбцов за запуск.
- Обстановка осадконакопления становится учебной меткой только тогда, когда она есть в выбранном столбце. Программа не выводит её из литологического описания.
- Тексты для обучения копируются из Excel без перевода. Если большинство выбранных описаний латиницей, запуск обучения блокируется: выберите русскоязычный столбец либо заранее подготовьте и проверьте русский перевод.
- Подтверждение в интерфейсе относится к соответствию фото, интервалов и текстовых описаний. Оно не означает независимую экспертную верификацию геологической интерпретации.
- Число обучающих примеров и их независимость ограничивают качество модели; перед научным или производственным применением нужна отдельная проверка на отложенных кернах.
