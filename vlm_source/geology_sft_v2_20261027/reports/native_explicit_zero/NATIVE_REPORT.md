# Проверка адаптера в локальном движке приложения, 28.10.2026

Одна и та же базовая Qwen3-VL-2B Q8_0/Vulkan, llama.cpp b11913, отвечает на 16 одинаковых сценариев.
Изменяется только явно заданное исследовательское применение LoRA к запросу; подготовка сообщений приложения сохраняется.
Для 15 вопросов найдена локальная справка, для одного промах поиска оставлен без подстановки эталона.

| Условие | Верно / частично / неверно | Завершено по оценке |
|---|---:|---:|
| База, подтверждённое отключение LoRA | 8 / 5 / 3 | 16/16 |
| Кандидат, LoRA ID 0 scale 1 | 7 / 8 / 1 | 16/16 |

32 текстовых запроса в четырёх слотах заняли 36.5551 с, включая 6.0160 с загрузки.
Это не замер анализа фотографий. Обеим условиям задан одинаковый лимит 650 токенов.

Контроль базы: `explicit-zero`. Проверка семантики: Pinned b11913 server-common.cpp L281-291 preserves an explicit zero entry; server-context.cpp L1764-1794 constructs zero scales for the nonempty request map and applies slot.lora at L3239. Baseline request_lora=[{id:0,scale:0.0}], candidate=[{id:0,scale:1.0}]. Empty-list initial run excluded. https://github.com/ggml-org/llama.cpp/blob/b11913/tools/server/server-context.cpp#L1776
GET со списком адаптеров подтверждает загрузку ID/пути; его scale сам по себе не доказывает состояние применения.

Интерпретация координатора: `rejected`. Кандидат не улучшил фактическую правильность: 7 верных ответов из 16 против 8 у базы. Рабочая модель сохраняется; экспериментальный адаптер не подключается.
Рабочие настройки приложения и активные веса не изменены. Конвертация GGUF не является одобрением модели.

Оценка ассистентом вслепую; геолог не проверял. Сценарии уже использовались при оценке HF.
Результаты HF FP16/160 и native Q8_0/650 нельзя использовать как изолированное сравнение эффекта квантования или LoRA.
Эта проверка не устанавливает качество полных описаний, фаций, независимых скважин или 95% точности.

Сырые ответы, включая ошибки, сохранены с SHA256 только для аудита и исключаются из справочного поиска.
Бинарные веса и фотографии в каталог отчётов не включены.
