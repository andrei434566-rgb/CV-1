Три источника дали четыре исходные фотопанели, 13 вырезок и только один новый керн с точным подклассом B — SAM9. Это не 13 независимых скважин. Возможное совпадение регионов с анонимизированными S-группами UniBo не скрывается; совпадений байтов/пикселей с доступными train/val не найдено. Закрытый проектный test не открывался.

Манифесты сохраняют DOI, URL, исходную панель, координаты, SHA256, авторское описание в русском пересказе, доступную глубину/её отсутствие, тип поверхности и условия публикации. Везде `geologist_approved=false`, соответствие 92 фациям не назначено. Полные страницы, подписи и вырезки просмотрены; порода не дорисовывалась и не перекрашивалась.
