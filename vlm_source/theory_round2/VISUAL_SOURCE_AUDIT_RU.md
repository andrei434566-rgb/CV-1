# Rock Image Datasets: инвентаризация 25.10.2026

Источник: [Mendeley](https://data.mendeley.com/datasets/7g7zpy9vcb/1), Alexis Pascual, DOI `10.17632/7g7zpy9vcb.1`. Лицензия **CC BY 4.0** подтверждена страницей и `data_licence` исходного API. Нужно сохранять атрибуцию, ссылку на лицензию и сведения об изменениях; наличие материалов третьих лиц может требовать отдельного разрешения согласно самому полю лицензии.

## Что получено

API версии подтверждает доступность V1. Files API содержит ровно один публичный файл:

- `rock_texture.mat`, **47 831 061 байт**, SHA-256 `aa5c2fe2c4a7843573b02774a345ec09000a1a1099b0ee5264781673f5d8fde7`.
- Скачан без аккаунта по URL, выданному API. Размер и SHA-256 совпали; исходный MAT сохранён без изменений.
- `textural_image`: массив `128×128×3×711`, float32, диапазон `[0,1]`.
- `labels`: `711×1`, значения **1…9**.
- Число фото по ID: **78, 69, 82, 86, 87, 83, 70, 83, 73** соответственно.
- Все 711 изображений уникальны по float-пикселям и после округления RGB в 8 бит. Точных дублей и конфликтов одинаковых пикселей между ID не найдено.
- В MAT отсутствуют названия классов, скважины, физические sample ID, исходные имена фото, глубины и train/val/test.

Проверка уникальности не исключает соседние фрагменты или повторные ракурсы одного физического образца. Контактный лист с тремя фото на numeric ID просмотрен; по нему не назначались геологические метки.

## Что известно о названиях и происхождении

Карточка связывает набор с диссертацией Lei Shu и работой Alexis Pascual. Первичная статья [Pascual et al., CCECE 2019](https://doi.org/10.1109/CCECE.2019.8861885), доступная как авторская копия, перечисляет девять названий: andesite, dolostone, granite, limestone, oolitic limestone, peridotite, red granite, rhyolite, volcanic breccia. Однако подпись её иллюстрации **не устанавливает соответствие числовым ID данного MAT**. Порядок в подписи или алфавитный порядок нельзя использовать как доказанную mapping.

Старый URL диссертации Western University сейчас переадресует на уведомление о переезде репозитория. Поиск публичного исходного кода и точного имени MAT не дал проверенной таблицы ID → название. Географию, число физических образцов и параметры исходной съёмки из MAT установить нельзя.

## Решение

**Сохранить в карантине, не экспортировать семантические обучающие пары.** Для подключения нужны:

1. Источниковая таблица numeric ID → geological class или доказуемая связь исходных иллюстраций с MAT, проверенная для всех ID.
2. Группы физических образцов/исходных фото, чтобы не оценивать соседние фрагменты одного камня как независимые данные.
3. Отдельная задача короткой классификации лабораторных текстур. Эти 128 px изображения не содержат готовых описаний керна, фаций или контуров.

Сохранены исходная API-метаинформация, `mendeley_7g7zpy9vcb_inventory.json`, построчный inventory без выдуманных названий и `numeric_ids_contact_sheet.png`. Карточки атрибуции и ссылок для будущей интеграции — `source_links.json`. Общая библиотека приложения не изменена.
