# Типовой Excel описания керна

Выгрузка через «Отчёт → Excel» использует шаблон с 31 столбцом A:AE и объединёнными заголовками. Для каждой скважины создаётся лист. Строка примера заменяется данными проекта. Можно выгрузить пустой бланк или частично заполненный отчёт.

| Столбцы | Источник |
| --- | --- |
| A:G | Месторождение, номер скважины, долбление, интервал отбора, стратиграфия, смещение по ГИС |
| H | Смещение внутри интервала из карточки слоя |
| I:J | Границы отбора по ГИС, D + G и E + G |
| K:M | Проходка, вынос и процент выноса, L / K × 100 |
| N:O | Кровля и подошва фации по бурению |
| P:Q | Кровля и подошва фации по ГИС, N + G + H и O + G + H |
| R:S | Номер строки слоя и толщина фации, O − N |
| T:V | Индекс, название и код выбранной фации |
| W:Z | Индекс, название и код макрофации, индекс ассоциации фаций |
| AA:AB | Ассоциация фаций и обстановка осадконакопления из карточки |
| AC:AE | Комплекс осадконакопления, краткое описание и примечания |

Общие данные вводятся в паспорте итогового Excel. Границы долблений определяют общий интервал отбора и номер долбления в каждой строке. Если слой пересекает границу долблений, в Excel появится строка для каждой части слоя.

В карточке слоя откройте «Поля отчёта». Доступные значения берутся из подключённого справочника и из предыдущих сохранённых выборов. Свои значения можно ввести прямо в поле. Пустая поправка H считается нулём для P и Q. Смещение G и поправка H учитываются со своими знаками.

Ячейки с проблемами отмечаются красным фоном с чёрным текстом. Excel пересчитывает подсветку после исправления данных. Замечания к исходному описанию доступны в примечании ячейки AD.
