# Итоговый Excel описания керна

Эталон: `app/resources/core_description_final_template.xlsx`, точная копия
переданного специалистом файла. Выгрузка Excel через меню приложения сохраняет
объединённые заголовки, порядок A:V и оформление исходного шаблона. Пример из
строки 4 удаляется. Для нескольких скважин создаётся отдельный лист на каждую
скважину с теми же колонками.

В файле 22 физические колонки, но 18 смысловых полей: четыре поля интервалов
занимают по две колонки.

| Поле | Колонки | Источник / правило |
| --- | --- | --- |
| 1 Месторождение | A | Заполняет специалист |
| 2 № скв. | B | Заполняет специалист |
| 3 № долбления | C | Специалист задаёт номера и интервалы долблений; номер меняется на границе интервала |
| 4 Интервал отбора керна | D:E | Минимальная кровля и максимальная подошва введённых долблений |
| 5 Стратиграфия | F | Заполняет специалист |
| 6 Смещение по ГИС | G | Заполняет специалист; может быть отрицательным или нулевым |
| 7 Интервал отбора по ГИС | H:I | Формулы D+G и E+G |
| 8 Проходка | J | Заполняет специалист |
| 9 Вынос керна, м | K | Заполняет специалист |
| 10 Вынос, % | L | Формула K/J×100 при J>0 |
| 11 Интервал фации по бурению | M:N | Границы слоя из разметки/сегментации |
| 12 Интервал фации по ГИС | O:P | Формулы M+G и N+G |
| 13 № слоя | Q | 1, 2, 3… по строкам каждого листа |
| 14 Толщина фации | R | Формула N−M |
| 15 Название фации | S | Класс интервала из сегментации/правки класса |
| 16 Ассоциация фаций | T | Только явный результат VLM |
| 17 Обстановка осадконакопления | U | Только явный результат VLM |
| 18 Краткое описание | V | Только явный результат VLM |

Поля специалиста вводятся в приложении через «File → Заполнить паспорт
итогового Excel…» или через контекстное меню скважины. Ввод сохраняется
в `project.json` вместе с проектом. Общие поля повторяются в строках фаций,
а C определяется по глубине каждой строки из таблицы долблений. Если фация
пересекает границу долблений, экспорт делит её на две строки на этой границе;
номер слоя и толщина пересчитываются для новых строк. Если глубина фации не
попала ни в одно долбление, C остаётся пустым. Пока паспорт не заполнен,
поля специалиста пусты. Формулы H, I, L,
O, P и R дают пустую ячейку, пока нужные числа не введены. Ноль в G является
допустимым смещением; ноль в J не используется как знаменатель. Для T:V
экспорт читает только `__vlm_facies_association`,
`__vlm_depositional_environment` и `__vlm_description` из атрибутов слоя.
Справочник фаций, импортированный текст Excel и генератор `best.pt` эти поля
автоматически не заполняют. До подключения локальной Qwen VLM они будут пусты.

Исходная строка примера имеет G=−1, H:I=D:E−1, но O:P=M:N+1. Последнее
противоречит заданному текстовому правилу. В экспорте закреплено одно правило
для обоих интервалов по ГИС: прибавлять G.
