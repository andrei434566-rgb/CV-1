# Открытые учебные материалы

Откройте **Настройки → Учебные материалы из открытых источников…** или напишите в чате **«открой учебные материалы»**. ZIP-архив можно также прикрепить в чат. Основное рабочее окно, итоговый Excel и справочник 92 фаций сохраняют прежний порядок работы.

## Как пользоваться

1. Выберите источник. Нажмите **«Скачать»** либо **«Выбрать архивы на ПК…»**, если материалы уже есть на диске.
2. Нажмите **«Подготовить материалы»**. Программа проверит структуру, сохранит происхождение записей и создаст отдельный набор. Загрузка и подготовка выполняются в фоне; операцию можно отменить. Незавершённую загрузку можно продолжить.
3. Нажмите **«Открыть результат»**. Для фото с описаниями откроется проверка: оригинал, изображение и поле вашего русского ответа. Подтверждайте только видимые признаки и корректный интервал. Если требуется вырезка слоя, подтверждение блокируется до отдельной подготовки изображения.
4. Проверенные пары передайте для обучения. Они попадут в существующее окно обучения описаний. Для разделения по скважинам нужны минимум две скважины. Назначение скважин в обучение и контроль сохраняется между экспортами.
5. Для готовой сегментации или классификации доступно **«Обучить модель…»**: выберите локальную исходную модель `.pt` нужного типа. Для обучения нужны NVIDIA, CUDA PyTorch и `ultralytics` в локальном Python. Приложение проверяет окружение перед запуском. Остановить обучение можно кнопкой **«Отменить операцию»**.

Результат обучения сохраняется отдельным кандидатом с паспортом и метриками. Подключение рабочей модели выполняется после проверки на ваших независимых скважинах. Метрики открытого набора не показывают точность полного геологического описания или 92 фаций проекта.

Классы источников сохраняются отдельно и не переименовываются автоматически в фации проекта. Классификация породы не создаёт подробного описания по фото.

## Контроль качества данных

- Фото и маски с несовпадающими размерами исключаются с причиной в отчёте. Для UniBo такая ошибка найдена у `S18_1.png`; произвольного растяжения маски нет.
- Разбиение выполняется до нарезки или обучения. У UniBo используются S-префиксы исходных файлов: это группировочные признаки, их соответствие независимым скважинам в README авторов не подтверждено. У Mendeley используются идентификаторы скважин. Исходные части пересекались по этим группам, поэтому для проекта они перегруппированы.
- Копии одинаковых изображений не допускаются одновременно в обучение и контроль. Неизвестная скважина или недостаточный контроль блокируют обучение.
- У CoreBreakout без дополнительного справочника скважин контроль делится по фотографиям; это ограничение видно в паспорте.
- Коды UKCS не превращаются автоматически в полные описания. В IODP проверяются идентификатор секции, половина керна и шкала глубины. Фото всей секции не считается вырезкой отдельного слоя.
- Оригинальные английские тексты сохраняются. Русское описание для обучения утверждает специалист; программа не выдаёт перевод за проверенную разметку.
- Для дообучения VLM экспортируются только явно подтверждённые пары. Подтверждения хранятся отдельно от исходных файлов; изменение фото или исходной записи отменяет старый допуск.

## Файлы и перенос

При работе из исходников библиотека находится в `open_datasets`, при работе из EXE — в `Kern Analyzer Data/open_datasets`. Архивы, подготовленные данные и результаты обучения не отправляются в Git. Для переноса материалов копируйте папку библиотеки целиком. Если файлы выбирались из другой папки, сохраните и их либо повторно выберите архивы на новом ПК.

Подготовленные текстовые документы подключаются к локальному поиску ассистента. Для ответов и обучения обращения к внешнему серверу не нужны; скачивание источников требует интернета. Ссылки в обычном чате показываются по запросу.

Для технической работы доступны команды:

```powershell
python scripts/open_datasets.py status
python scripts/open_datasets.py download --source corebreakout
python scripts/open_datasets.py prepare --source corebreakout
```

Идентификаторы: `corebreakout`, `unibo`, `ukcs`, `iodp362`, `dcid`, `mendeley`. По умолчанию IODP скачивается как ограниченный пилот; полная коллекция фотографий значительно больше. Ручная загрузка архивов поддерживается тем же окном.

Подготовка: `scripts/prepare_unibo_vlm_facies.py`, обучение: `scripts/train_unibo_visual_facies.py`. Его исходные метки масок не являются утверждёнными специалистом фациями проекта.
